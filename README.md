# Board SFX 🎛️

A free, lightweight soundboard for Windows that uses your keyboard as input, no dedicated hardware deck required.

Bind a key to a sound, and it fires instantly over any application: OBS, games, Discord, browser, and more.

🔗 **Website:** [boardsfx.fun](https://www.boardsfx.fun/)

## Features

- Bind any key on your keyboard to a sound effect
- Fires sounds instantly, works alongside any application (OBS, games, browser, etc.)
- Lightweight: ~15MB install size, ~5MB RAM usage in the background
- No drivers or additional hardware required
- Runs quietly in the background

## System Requirements

- Windows 10 or Windows 11

## Installation

1. Download the latest release: [V0.1.0](https://github.com/yohanesrioirsan/boardsfx-release/releases/tag/V0.1.0)
2. Run the installer
3. Bind your keys and start firing sounds
